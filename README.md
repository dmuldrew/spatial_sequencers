# spatial_sequencers

Team workspace for the 2026 NASA International Space Apps Challenge (Seattle).
Forked from dmuldrew/spatial_sequencers and restructured so each project
lives in its own subfolder.

## Sub-projects

### PyroSync — `pyrosync/`

Interactive NASA Fire-Weather Observatory & spatial audio-visual sequencer
(NASA FIRMS fire data; d3 + Tone.js). Live demo: https://lanly-dev.github.io/spatial_sequencers/pyrosync/
Project hub: https://lanly-dev.github.io/spatial_sequencers/

Run locally:

    cd pyrosync
    npm install
    npm start

See `pyrosync/README.md` for the original project notes and the challenge
summaries this work grew out of.

### Space Jukebox — `space-jukebox/`

Sonification of NASA/NOAA Earth data, built for blind and low-vision
listeners first (The Earth Information Jukebox challenge). One
self-contained page — live demo:
https://lanly-dev.github.io/spatial_sequencers/space-jukebox/
